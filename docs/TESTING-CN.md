# Pico Launcher CN 0.1.1 文件名显示版测试记录

日期：2026-10-25（北京时间）。状态：电脑验证通过，真机验证待完成。

0.1.0 已获得用户“可以正常看到 banner 的中文”反馈，机型未提供。0.1.1 新增的文件名显示行为仍待真机确认。

## 已完成

- 使用相同的 BlocksDS 1.24.0／ARM GCC 16.2 工具链先构建官方基线，再构建中文版本，均成功。
- 官方基线为 491,008 字节，文件名显示版为 1,502,720 字节，新增 1,011,712 字节。
- 检查了列表与上屏两处 UI 绑定，均直接把实际文件名作为标题，不再调用 banner 标题；图标与封面的读取链保持原有逻辑。Material 和自定义主题均将主标题缓冲区扩至 256 个 UTF-16 单元。
- 只读检查《黄金太阳 漆黑的黎明》汉化 ROM（BO5J）：banner v1 的日、英、法、德、意、西六栏都是同一段日文，未包含中文标题。其文件名有中文，因此新版将直接显示文件名。
- 两套新增 NFT2 字体共 1,011,482 字节，各覆盖 7,447 个字符，其中有 6,763 个 GB2312 汉字。验证了全部必需字符的映射、可见汉字位图、偏移、字形尺寸及行高范围。
- 四套原有 NotoSansJP 字体逐字节 SHA256 校验一致。
- 用项目实际的 C++ 文字绘制代码，通过四套主字体验证了中文补充、宽度计算、裁切、两行文字、长标题省略和输出缓冲区前后保护区。
- 每个像素对比了 2D tile 与 3D A5I3 两种绘制输出。
- 验证中文 banner 优先选择、首行空白清理、仅空格的中文栏回退、DS v1 标题版本限制、日文回退及全空标题。
- 验证原有 UTF-8 中文文件名解码及按 UTF-16 字符截断。
- 只读提取用户指定的日版《黑2》汉化 ROM（IREJ）banner。选中的标题以“精灵宝可梦 黑2”开头，第二行为 Nintendo。
- 新生成 NDS 文件的文件头 CRC、Nintendo Logo CRC 和菜单自身 banner CRC 全部匹配。保留原版 DS／DSi 增强类型（unit code 2）。
- 链接地图中的常驻数据增加约 0.97 MiB。按 DS 模式链接窗口和原有堆初始化保留量估算，动态堆初始化前可用池约 2.09 MiB；这不是运行后的剩余内存实测值。

## 结果文件

`releases/0.1.1-filename-test/` 中的 `validation.json` 记录字体覆盖数、二进制 SHA256、CRC 结果及 `title_source=filename`；`native-tests.txt` 保存 C++ 测试结论。`docs/previews/` 的两张 PNG 由实际 C++ 输出像素合成，按最近邻放大，属于电脑绘制预览。程序直接提供为 `_picoboot.nds`，不再打安装 ZIP。

## 已知范围

当前字库以常用简体字符为主，未覆盖完整 CJK／繁体／扩展区汉字。原版菜单中关于其他语言、游戏加载和存档的功能未重新做全量回归。字体采用 9／12 像素补充，尤其小字号下复杂汉字的实际可读性仍需在 DS 屏幕上确认。
